READ THIS BEFORE OPENING ANY OF THEM
  A gate is content the game runs only in one episode, so opening it makes
  that content unconditional. NOT every gate should be opened. Many pick
  between two equally valid per-episode values - a constant, a model name, a
  sound - and forcing one overrides the other episode's. We already hit this:
  a patch labelled 'E2 Bullet traces' was landing on a `cmp episode,1` that
  chooses between the PU_SEADONE and PU_SEADONEE2 pickup names, and forcing
  it pinned a pickup name in every episode for no benefit.

  The `cmp episode, 3` entries are bounds checks - there is no episode 3.
  Listed only for completeness. Ignore them.
